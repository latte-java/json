# Plan 3: Type-Coverage Extras Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Extend the annotation processor so `@JSON` records may additionally use these component types: `BigInteger`, `BigDecimal`, any `enum`, `UUID`, and the `java.time` types `Instant`, `LocalDate`, `LocalDateTime`, `OffsetDateTime`, `ZonedDateTime`, `Duration`, `Period`. Default representations only (enum → `name()`/`valueOf`; UUID & java.time → ISO string via `toString`/`parse`). Custom date formats (`@JSONField(format=…)`) and all other `@JSONField`/naming/catch-all remain Plan 5.

**Architecture:** New drift-guarded helper `Conversions` (string-form parsers that wrap `IllegalArgumentException`/`DateTimeException` in `JSONProcessingException`, mirroring the `Numbers` pattern) plus one new `Numbers.toBigIntegerExact(BigDecimal)`. `JSONProcessor` is extended at four well-known seams identified by the Plan-2 holistic review: `isSupportedComponentType`, `simpleType`, `builderCall` (serialization), and the three `*Narrowing` tables + the `string` callback switch (deserialization). No structural rewrite — pure extension. Verified via the existing `JavaCompiler`-API harness with new fixtures.

**Tech Stack:** Java 25, `javax.annotation.processing`/`javax.lang.model`, TestNG, Latte build. Conventions identical to Plan 2 (SPDX single-year 2026, `@author Brian Pontarelli`, `import module java.base;` + only necessary disambiguators, `[brackets]` in messages, strict alphabetical members, no inter-field blank lines; these apply to generated code too — generated companions carry the "Generated by org.lattejava.json.JSONProcessor. Do not edit." Javadoc).

> **Module-import disambiguation:** any TestNG test referencing `java.nio.file.Files` keeps `import module java.base;` and adds `import java.nio.file.Files;` (collides with `org.testng.reporters.Files`). `ProcessorHarness` is unaffected (no `org.testng`). New `Conversions` uses `import module java.base;` (covers `java.util.UUID`, `java.time.*`, `java.math.*`).

**Spec:** `docs/design/2026-05-12-serialization.md` (authoritative — see the Type-coverage table for exact wire forms and the Errors section: enum/UUID/date parse failures and numeric width/precision mismatches must surface as `JSONProcessingException`).

**Scope guardrails (Plan 3 only):**
- Still records only; still primitives/boxed/String from Plan 2 PLUS the types listed above. Anything else (collections, nested `@JSON`, `Optional`, arrays, `char`, `byte[]`) stays a compile-time error.
- Default representations only. `@JSONField` (incl. `format`), naming strategies, `@JSONCatchAll`, polymorphism, non-record classes remain later plans; the processor must not crash on them but their presence does not change Plan-3 output.
- `enum` is detected structurally (a `DECLARED` type whose element `getKind() == ENUM`), so user enums in any package work without enumerating them.
- java.time parsing uses each type's built-in `parse(CharSequence)` (ISO-8601). No custom formats in Plan 3.

```java
/*
 * Copyright (c) 2026 The Latte Project
 * SPDX-License-Identifier: MIT
 */
package org.lattejava.json;

import module java.base;

/**
 * String-form parsers for {@code @JSON} component types whose wire form is a JSON string (enums,
 * {@code UUID}, and the ISO-8601 {@code java.time} types). Each method wraps the JDK's
 * {@link IllegalArgumentException} / {@link java.time.DateTimeException} in
 * {@link JSONProcessingException} so all parse failures share one exception type. Codegen calls these
 * instead of inlining try/catch at every site.
 *
 * @author Brian Pontarelli
 */
public final class Conversions {
  private Conversions() {
  }

  public static Duration toDuration(String value) {
    try {
      return Duration.parse(value);
    } catch (DateTimeException e) {
      throw new JSONProcessingException("Value [" + value + "] is not a valid Duration", e);
    }
  }

  public static <E extends Enum<E>> E toEnum(Class<E> type, String value) {
    try {
      return Enum.valueOf(type, value);
    } catch (IllegalArgumentException e) {
      throw new JSONProcessingException(
          "Value [" + value + "] is not a constant of enum [" + type.getSimpleName() + "]", e);
    }
  }

  public static Instant toInstant(String value) {
    try {
      return Instant.parse(value);
    } catch (DateTimeException e) {
      throw new JSONProcessingException("Value [" + value + "] is not a valid Instant", e);
    }
  }

  public static LocalDate toLocalDate(String value) {
    try {
      return LocalDate.parse(value);
    } catch (DateTimeException e) {
      throw new JSONProcessingException("Value [" + value + "] is not a valid LocalDate", e);
    }
  }

  public static LocalDateTime toLocalDateTime(String value) {
    try {
      return LocalDateTime.parse(value);
    } catch (DateTimeException e) {
      throw new JSONProcessingException("Value [" + value + "] is not a valid LocalDateTime", e);
    }
  }

  public static OffsetDateTime toOffsetDateTime(String value) {
    try {
      return OffsetDateTime.parse(value);
    } catch (DateTimeException e) {
      throw new JSONProcessingException("Value [" + value + "] is not a valid OffsetDateTime", e);
    }
  }

  public static Period toPeriod(String value) {
    try {
      return Period.parse(value);
    } catch (DateTimeException e) {
      throw new JSONProcessingException("Value [" + value + "] is not a valid Period", e);
    }
  }

  public static UUID toUUID(String value) {
    try {
      return UUID.fromString(value);
    } catch (IllegalArgumentException e) {
      throw new JSONProcessingException("Value [" + value + "] is not a valid UUID", e);
    }
  }

  public static ZonedDateTime toZonedDateTime(String value) {
    try {
      return ZonedDateTime.parse(value);
    } catch (DateTimeException e) {
      throw new JSONProcessingException("Value [" + value + "] is not a valid ZonedDateTime", e);
    }
  }
}
```

(`DateTimeException` is the supertype of `DateTimeParseException`; `import module java.base;` covers `java.time.*`, `java.util.UUID`, `java.time.format`. Methods alphabetical: `toDuration, toEnum, toInstant, toLocalDate, toLocalDateTime, toOffsetDateTime, toPeriod, toUUID, toZonedDateTime`.)

Replace the method with:

```java
  private boolean isSupportedComponentType(TypeMirror t) {
    if (t.getKind().isPrimitive()) {
      return true;
    }
    if (t.getKind() == TypeKind.DECLARED) {
      var element = ((javax.lang.model.type.DeclaredType) t).asElement();
      if (element.getKind() == ElementKind.ENUM) {
        return true;
      }
      String name = t.toString();
      return switch (name) {
        case "java.lang.String", "java.lang.Boolean", "java.lang.Byte",
             "java.lang.Short", "java.lang.Integer", "java.lang.Long",
             "java.lang.Float", "java.lang.Double",
             "java.math.BigInteger", "java.math.BigDecimal",
             "java.util.UUID",
             "java.time.Instant", "java.time.LocalDate", "java.time.LocalDateTime",
             "java.time.OffsetDateTime", "java.time.ZonedDateTime",
             "java.time.Duration", "java.time.Period" -> true;
        default -> false;
      };
    }
    return false;
  }
```

(`DeclaredType` is referenced fully-qualified to avoid touching the import block; `ElementKind` resolves via `import module java.compiler;` already present.)
